# 감리원 배치표 작성

발주청 제공 배치계획표 원본(PDF/xlsx) + 입찰설명서/공고문(PDF/HWP) → 수식이 살아있는 완성 배치표(xlsx).
아래 절차와 규칙을 그대로 따른다. 컨소사 업체명·조정PQ지분은 사용자가 직접 입력하는 칸으로 남기되, 노란색으로 칠하지 않는다(노랑은 PQ평가대상 표시 전용).

## 0. 준비
- 두 번째 파일은 '입찰설명서' 또는 '공고문'이며, PDF뿐 아니라 한글(HWP)일 수도 있다.
  - PDF는 pdfplumber로 텍스트 추출(구조가 헷갈리면 pdftoppm으로 이미지 렌더 후 눈으로 확인).
  - HWP는 hwp5txt(pyhwp)/olefile 등으로 텍스트 추출을 시도하고, 안 읽히면 사용자에게 PDF로 변환해 첨부를 요청한다.
- 두 파일이 작업공간(bash)에서 안 읽히면 사용자에게 채팅창에 첨부를 요청한다(uploads로 들어와 읽힌다).
- 엑셀 작성은 openpyxl, 검증은 xlsx 스킬의 scripts/recalc.py(LibreOffice 재계산)로 한다.

## 1. 배치계획표 원본에서 읽을 것
각 인원: 구분(상주/비상주=기술지원), 역할(책임/보조), 분야, 등급, 감리원, 월별 배치값(0.5·1.0), 비고.
- 개월수(nM)와 시공단계/시공후 경계를 반드시 확인한다. 헤더 "시공단계"/"시공후"가 어느 월에 걸리는지 본다. 시공후 칸이 없으면 전 기간 시공단계.
- 비상주는 보통 월 표시 없이 투입월수만 있으나, 확정 양식에서는 비상주도 상주처럼 월별 1.0을 채우고 투입월수는 =SUM 수식으로 둔다.
- 투입월수 총계(상주+비상주)는 원본 총계와 일치해야 한다(검산).

## 2. 입찰설명서/공고문에서 읽을 것
- 용역명, 용역예정금액(=용역금액), 용역기간(착수일로부터 N일 ≈ 개월수).
- 과업별 분담비율(공종별 비율): 예 건설엔지니어링업 100% 또는 건설 91%·통신 6%·소방 3%.
- 12.1 배치현황(평가대상) 표: 'PQ/평가' 표시 직무분야 = PQ평가대상(노랑 대상). 거기 등급은 배치표 등급과 대조.
- 낙찰하한율 명시 없으면 기본 0.79995.

## 3. 시공후 계산 O/X
- 상주 O·기술지원 X(상주는 시공후 배치, 기술지원은 미배치)일 때만 시공단계/시공후 칸을 나눠 계산(O).
- 둘 다 시공후에 있거나 시공후 단계 자체가 없으면 단일 계산(X): 투입월수·환산비·인월수·% 한 세트.

## 4. 환산비
- 등급 기준: 특급 1.061 / 고급 1.0 / 중급 0.931 / 초급 0.764.
- 통신 상주는 건설 환산비가 아니라 통신 전용 환산비(통신 중급 0.753) 적용.
- 소방 기술지원은 환산비 0.695(참고자료 반올림값) 사용.

## 5. 인월수
- 상주: 인월수 = 투입월수 × 환산비. (split이면 인월수(시공단계)=투입단계×환산, 인월수(시공후)=투입후×환산)
- 기술지원(비상주) 분야별 정석:
  - 건설(건축·구조·토목·조경·기계): 그룹총 = 건설 상주 환산인월수합 × 공종계수(단순 0.10/0.90·보통 0.15/0.85·복잡 0.20/0.80). 각 인원 = 그룹총 × (그 인원 투입월수 ÷ 건설기지 투입월합). split이면 base는 상주 시공단계 인월수합.
  - 통신: = 통신 상주 인월수(시공후 포함) × 0.10/0.90.
  - 소방: = 소방 투입월수 ÷ 4.4 × 환산비(0.695).
  - 표기: 기술지원 환산비 칸에는 '인월수 계산값'을 넣는다(건설은 그룹총을 병합칸에, 통신은 인월수). 단 소방만 환산비 칸에 환산비를 둔다.
  - split일 때 인월수(시공단계) 칸에 실제 산식, 인월수(시공후) 칸은 =시공단계 참조. (소방은 시공단계=투입단계/4.4×환산비, 시공후=투입후/4.4×환산비로 각각)
- 학교는 보통공종. 운동·문화집회·의료시설 등은 복잡, 공장·창고 등은 단순.

## 6. 소계·합계·%
- 상주기술인 소계, 기술지원기술인 소계, 총계(합계) 행. 월 영역은 한 칸으로 병합.
- % = 인월수(시공후) ÷ 합계 인월수.

## 7. 하단 우측 '산정기준 + 공동지분표'
- 산정기준: 용역금액(입력), 낙찰하한율(0.79995), 기초금액 = 용역금액×낙찰하한율, 공종(건설) 입력 + 환산계수(IF) 1칸. 값 칸은 빈 칸 없이 병합.
- 지분표 열: 구분 | 컨소사 | 실지분 | 조정PQ지분 | 예상지분금액 | 지역참여도 | 공종별비율.
  - 구분 = 건설(여러 컨소사 행) / 통신 / 소방(있을 때만). 조정PQ지분은 건설만.
  - 실지분은 공종별로 분리해 SUMIF: 건설사 실지분 = 건설 상주+건설 기지 행에서 그 업체 % 합. 통신 = 통신상주%+통신기지%. 소방 = 소방기지%. (합 100%)
  - 예상지분금액 = 기초금액 × 실지분.
  - 지역참여도 = (지역사 건설 조정PQ × 건설공종비율) + 통신공종비율 + 소방공종비율.
  - 공종별비율 = 입찰설명서/공고문 분담비율.
- 컨소사 광장(책임,1번째)·케이제이(2번째)는 고정, 나머지는 입력칸(노랑 아님).

## 8. 서식
- 글꼴 맑은 고딕 통일.
- 소숫점: 투입월수·환산비·인월수 0.00, %는 0.00%, 금액 #,##0.
- 노랑 = PQ평가대상 행만(그 행의 분야·등급·감리원·컨소사 칸). 비평가 행과 컨소사·조정PQ 입력칸은 노랑 없음.
- 조정PQ지분 칸 = 빨강(medium) 좌측 테두리.
- 표 테두리는 내용 있는 셀에만. 빈 칸까지 테두리 채우지 말 것. 칸 너비 과하게 넓히지 말 것(비고 ~11).
- 소계 연녹(E2EFDA), 합계 연주황(FCE4D6), 헤더 살구(F2DCDB), 조정PQ헤더 강조(FFE699).
- 책임 비고 '총괄', 안전담당 '안전'. 하단 ※ 문구 3개 유지:
  1) 본 배치계획서는 발주기관 및 사업진행 상황에 따라 조정될 수 있음
  2) 본 용역의 계약자는 용역 착수 전에 수요기관과 협의하여 본 계약내용의 범위 및 법적 기준 내에서 배치계획을 조정할 수 있음
  3) 기술지원 건설사업관리기술자(비상주)는 매월 1회 이상 현장방문하여 점검·확인·평가하고 기술지도(또는 행정지원)하여야 함

## 9. 등급 대조
입찰설명서/공고문 12.1 평가대상 등급과 배치표 등급을 비교해 상이하면 빨간 글씨로 표시(같으면 표시 없음).

## 10. 검증(필수)
recalc.py 재계산 후: 수식 오류 0개, 투입월수 총계 = 원본 총계, 실지분 합 = 100%, 예상지분금액 합 = 기초금액, % 합 = 100%.
