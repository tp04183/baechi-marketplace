# 감리원 배치표 작성

발주청 제공 배치계획표 원본(PDF/xlsx) + 입찰설명서/공고문(PDF/HWP/HWPX) → 수식이 살아있는 완성 배치표(xlsx).
컨소사 업체명·조정PQ지분은 사용자 입력칸으로 남긴다. 여러 세트를 주면 순서대로 하나씩 완성한다.

## 0. 준비
- 둘째 파일(입찰설명서/공고문)은 PDF 또는 한글(HWP/HWPX)일 수 있다. PDF=pdfplumber(스캔본은 pdftoppm 렌더), HWPX=zip의 Contents/section0.xml `<hp:t>` 추출, HWP=hwp5txt/olefile 시도.
- 원본 배치표가 .xls(구형)면 LibreOffice로 xlsx 변환 후 읽는다. #REF!·외부참조가 많으면 실제 배치된 인원만 추려 표준 형식으로 정리한다.
- 엑셀=openpyxl. 검증=xlsx 스킬 scripts/recalc.py(LibreOffice). 재계산이 시간초과하면 렌더 이미지의 계산값(오류표시 없음)으로 대신한다. bash에서 파일이 안 읽히면 사용자에게 채팅 첨부 요청.

## 0-1. 이미 계산된 '배치표(안)'인 경우
원본에 환산비·환산인월수까지 기입돼 있으면 그 값·산식(통신·소방 특수식, 비표준 환산비 포함)을 그대로 쓰고 컨소사·%·지분표·서식만 추가한다(재계산 X, 사용자 확인). 단, 안이 외부참조로 깨져 값이 안 나오면 표준 규칙으로 재계산하고 알린다.

## 1. 배치계획표 원본에서 읽을 것
각 인원: 구분(상주/비상주=기술지원), 역할(책임/보조), 분야, 등급, 월별 배치값(0.5·1.0), 비고.
- 개월수(nM)와 시공단계/시공후 경계 확인. 월별 소계로 배치월 검산.
- 원본에 실제 배치된 인원만 옮긴다(미배치 예비행 제외). 배치현황(설명서)과 대조.
- 비상주(기술지원)는 원본에 표시된 **실제 배치구간만 점선 배치바로** 표시한다. 뒤쪽 일부 구간만 배치된 경우(예: 소방)는 그 구간만 그리고 투입월수도 그 개월수로 한다.
- 투입월수 총계(상주+비상주) = 원본 총계(검산).

## 2. 입찰설명서/공고문에서 읽을 것
- 용역명, 용역예정금액(=용역금액), 용역기간(N일 ≈ 개월수).
- 분담비율(공종별 비율): 예 건설 100% / 건설·통신·소방 분할.
- 배치현황: 'PQ/평가' 표시 직무분야 = PQ평가대상(등급은 배치표와 대조). 같은 분야도 상주/기술지원에서 PQ 여부가 다를 수 있으니 행별 판단.
- 낙찰하한율 명시 없으면 0.79995.

## 3. 시공후 계산 O/X
- 상주 중 한 명이라도 시공후 배치 & 기술지원은 시공후 없음 → 분리(O). 투입월수(시공후)=시공후 포함 총 개월수.
- 모두 시공후에 있거나 시공후 단계가 없으면 → 단일(X): 투입월수·환산비·인월수·% 한 세트.

## 4. 환산비
- 등급: 특급 1.061 / 고급 1.0 / 중급 0.931 / 초급 0.764.
- 통신 상주=통신 전용(통신 중급 0.753), 소방 기술지원=0.695. (배치표안에 값 있으면 그 값)

## 5. 인월수
- 상주: 투입월수 × 환산비. (split이면 시공단계/시공후 각각)
- 기술지원(비상주):
  - 건설(건축·구조·토목·조경·기계): 그룹총 = 건설 상주 환산인월수합 × 공종계수. 각 인원 = 그룹총 × (투입월수 ÷ 건설기지 투입월합). split이면 base=상주 시공단계 인월수합.
  - 통신 = 통신 상주 인월수 × 0.10/0.90. 소방 = 소방 투입월수 ÷ 4.4 × 0.695.
  - 공종계수는 항상 표준값(단순 0.10/0.90·보통 0.15/0.85·복잡 0.20/0.80)을 IF수식으로 두고 '공종(건설)' 입력에 연동. 배치표에 '15%' 표기가 있어도 표준 적용.
  - **기술지원 투입월수 = 실제 배치개월.** 통상 시공단계 전체지만 특정 분야(구조검토·소방 등)는 원본대로 일부만. 이 값이 건설기지 투입월합·배분에 영향.
  - 비고에 '월N회'면 투입월수·배분가중치 = 개월수 × N.
  - 표기: 기술지원 환산비 칸엔 인월수 계산값(건설=그룹총 병합칸, 통신=인월수). 소방만 환산비 칸에 환산비(0.695). split이면 인월수(시공후)=시공단계 참조.
  - ※ 배치표안(0-1)이면 안의 값·산식 그대로.
- 공종: 학교·유치원·중학교=보통, 운동·문화집회·의료=복잡, 공장·창고=단순.

## 6. 소계·합계·%
상주 소계 / 기술지원 소계 / 총계. % = 인월수(시공후) ÷ 총계 인월수.

## 7. 하단 우측 '산정기준 + 공동지분표'
- **블록 전체를 본표 비고열(맨 오른쪽) 끝에 맞춰 우측정렬**하고, 산정기준을 지분표 바로 왼쪽에 접하게 둔다(빈 열 없음). 행높이 통일.
- 금액·계수·% 값이 **### 없이 다 보이게** 열 폭을 충분히: 금액 필드는 넓은 우측 열(투입월수·인월수 등) 위에 놓고 병합 폭을 넉넉히, % 열은 100.00%가 들어가게. 단일계산(시공후X)처럼 넓은 열이 적으면 지분표가 걸치는 월열 폭을 넓힌다. 기지계수 라벨은 한 줄(자동 축소), 값칸 3칸 병합(0.000).
- 산정기준: 용역금액(입력) / 낙찰하한율(0.79995) / 기초금액=용역금액×낙찰하한율 / 공종(건설) 입력 + 공종계수 IF수식.
- 지분표 열: 구분 | 컨소사 | 실지분 | 조정PQ지분 | 예상지분금액(2칸) | 지역참여도 | 공종별비율.
  - 구분 = 건설(여러 컨소사 행)/통신/소방(있을 때만). 건설 100%면 건설 행만. 조정PQ지분은 건설만.
  - 실지분 = 공종별 SUMIF(건설=건설상주+건설기지 %, 통신=통신상주%+통신기지%, 소방=소방기지%). 컨소사(G열) 입력 시 합 100%.
  - 예상지분금액 = 기초금액 × 실지분. 지역참여도 = (지역사 건설 조정PQ × 건설비율) + 통신·소방 비율. 공종별비율 = 분담비율.
  - **합계행에 실지분·조정PQ·예상지분금액·지역참여도·공종별비율 모두 합산(공종별비율=100%).**
- 컨소사 광장(책임,1번째)·케이제이(2번째) 고정, 나머지 입력칸.

## 8. 서식
- 글꼴 맑은 고딕. 소숫점: 투입월수·환산비·인월수 0.00, % 0.00%, 금액 #,##0. 비고 가운데.
- **노랑 = PQ평가대상 행의 분야·등급·컨소사만** (감리원·비평가행·지분표 입력칸은 노랑 없음).
- **조정PQ지분 = 헤더부터 입력칸까지 열 전체를 빨강 굵은(medium) 바깥 테두리, 입력 수치는 굵게.**
- 테두리: 본표는 내용 있는 셀만(빈 월칸 O, 표 바깥 확장 X), 하단블록은 전 셀.
- 색: 소계 연녹(E2EFDA), 합계 연주황(FCE4D6), 헤더 살구(F2DCDB).
- **하단 ※/주) 문구는 원본에 있을 때만 그대로. 없으면 안 씀(임의 생성 금지).** 상주 비고도 원본에 없으면 공란. 단 기술지원 현장방문 비고는 [1회/월]·[1회/주]로 통일.
- 제목행(1행) 높이 30으로 두어 20pt 제목이 잘리지 않게 한다.

## 9. 등급 대조
설명서 평가대상 등급 ≠ 배치표 등급이면 빨간 글씨(같으면 표시 없음).

## 10. 인쇄 설정
A4 세로, fitToWidth=1·fitToHeight=0. **시트 뷰를 '페이지 나누기 미리보기'(pageBreakPreview)로 저장하고 인쇄영역(B1~비고열·마지막행) 지정.**

## 11. 검증(필수)
수식 오류 0, 투입월수 총계=원본 총계, % 합 100%, 공종별비율 합 100%, (컨소사 입력 시) 실지분 합 100%·예상지분금액 합=기초금액. 렌더로 ### 잘림·비고열 정렬·테두리·페이지나누기·하단 문구·비상주 배치구간까지 눈으로 확인.
