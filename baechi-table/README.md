# 배치표 작성 (baechi-table)

발주청이 준 **배치계획표 원본(PDF/엑셀)**과 **입찰설명서(PDF)** 두 파일을 주면,
환산비·인월수·지분율·공동지분표까지 수식으로 계산된 **완성 배치표(xlsx)**를 만들어 줍니다.

## 쓰는 법
Cowork에서: "독도교육원 배치표 만들어줘" 라고 하고 배치표 원본 + 입찰설명서 두 파일을 첨부(또는 폴더 지정)하세요.

## 무엇을 자동으로 하나
- 원본에서 인원·분야·등급·월별 배치·시공후단계 인식
- 입찰설명서에서 용역금액·기간·공종별 분담비율·PQ평가대상·등급 추출
- 시공후 계산 O/X 판단, 환산비(통신 0.753·소방 0.695 포함), 공종별 기술지원 인월수
- 소계/합계·%, 공동지분표(실지분·예상지분금액·지역참여도), PQ대상 노랑·조정PQ 빨강테두리 등 서식
- 등급 입찰설명서 대조(상이 시 빨강), 수식 오류 0·지분율 100% 검증

## 직접 입력(노란 칸)
컨소사 업체명, 조정PQ지분 (책임=광장·2번째=케이제이 고정)
