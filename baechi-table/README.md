# 감리원 배치표 작성

발주청 제공 배치계획표 원본(PDF/xlsx) + 입찰설명서/공고문(PDF/HWP/HWPX) → 수식이 살아있는 완성 배치표(xlsx).
아래 절차·규칙을 그대로 따른다. 컨소사 업체명·조정PQ지분은 사용자가 직접 입력하는 칸으로 남긴다.

## 0. 준비
- 둘째 파일은 '입찰설명서' 또는 '공고문'이며 PDF뿐 아니라 한글(HWP/HWPX)일 수 있다.
  - PDF는 pdfplumber, 구조 헷갈리면 pdftoppm 렌더 후 확인.
  - HWPX는 zip이므로 Contents/section0.xml의 <hp:t> 텍스트 추출. HWP(구형)는 hwp5txt/olefile 시도, 안 되면 PDF 변환 요청.
- 파일이 bash에서 안 읽히면 사용자에게 채팅 첨부 요청(uploads로 들어옴).
- 엑셀은 openpyxl, 검증은 xlsx 스킬 scripts/recalc.py(LibreOffice 재계산).

## 1. 배치계획표 원본에서 읽을 것
각 인원: 구분(상주/비상주=기술지원), 역할(책임/보조), 분야, 등급, 감리원, 월별 배치값(0.5·1.0), 비고.
- 개월수(nM)와 시공단계/시공후 경계 확인. 시공후 칸 없으면 전 기간 시공단계.
- 비상주도 상주처럼 월별 1.0을 채우고 투입월수는 =SUM 수식으로.
- 비고 문구는 원본에 적힌 그대로 읽어 그대로 옮긴다(임의 가공 금지).
- 투입월수 총계(상주+비상주)는 원본 총계와 일치(검산).

## 2. 입찰설명서/공고문에서 읽을 것
- 용역명, 용역예정금액(=용역금액), 용역기간(N일 ≈ 개월수).
- 과업별 분담비율(공종별 비율): 예 건설 100% 또는 건설 93%·통신 5%·소방 2%.
- 12.1 배치현황(평가대상): 'PQ/평가' 표시 직무분야 = PQ평가대상. 등급은 배치표와 대조.
  - 같은 분야명이라도 상주/기술지원에서 PQ 여부가 다를 수 있다(예: 기계 상주 평가대상, 기계 기지 비대상). 행별 판단.
- 낙찰하한율 명시 없으면 0.79995.

## 3. 시공후 계산 O/X
- 상주 O·기술지원 X일 때만 시공단계/시공후 분리(O). 이때 투입월수(시공후)는 "시공후까지 포함한 총 개월수"다(시공후만이 아님).
- 둘 다 시공후에 있거나 시공후 단계가 없으면 단일(X): 투입월수·환산비·인월수·% 한 세트.

## 4. 환산비
- 등급: 특급 1.061 / 고급 1.0 / 중급 0.931 / 초급 0.764.
- 통신 상주는 통신 전용 환산비(통신 중급 0.753). 소방 기술지원은 0.695.

## 5. 인월수
- 상주: 투입월수 × 환산비. (split이면 시공단계/시공후 각각)
- 기술지원(비상주) 분야별:
  - 건설(건축·구조·토목·조경·기계): 그룹총 = 건설 상주 환산인월수합 × 공종계수. 각 인원 = 그룹총 × (그 인원 투입월수 ÷ 건설기지 투입월합). split이면 base는 상주 시공단계 인월수합.
  - 통신: 통신 상주 인월수(시공후 포함) × 0.10/0.90.
  - 소방: 소방 투입월수 ÷ 4.4 × 0.695.
  - 공종계수는 항상 공종 기준 표준값(단순 0.10/0.90·보통 0.15/0.85·복잡 0.20/0.80)을 IF수식으로 두고 '공종(건설)' 입력에 연동. 배치표에 '15%' 등 표기가 있어도 표준 공종계수를 적용.
  - **비고에 '월N회'(예 월2회)가 있으면 그 인원의 투입월수(및 배분 가중치)는 개월수 × N으로 둔다(투입월수 칸도 =SUM(월)×N). 예: 구조기술사 월2회, 6개월 → 12.**
  - 표기: 기술지원 환산비 칸에는 인월수 계산값(건설=그룹총 병합칸, 통신=인월수). 소방만 환산비 칸에 환산비. split이면 인월수(시공단계)에 산식, 인월수(시공후)는 =시공단계 참조. (소방은 시공단계=투입단계/4.4×환산, 시공후=투입후/4.4×환산)
- 학교·유치원·중학교는 보통공종. 운동·문화집회·의료시설 등 복잡, 공장·창고 등 단순.

## 6. 소계·합계·%
- 상주기술인 소계, 기술지원기술인 소계, 합계(총계). 월 영역 한 칸 병합. % = 인월수(시공후) ÷ 합계 인월수.

## 7. 하단 우측 '산정기준 + 공동지분표'
- 블록은 본표 오른쪽 끝에 맞춰 배치, 행높이 통일(넓게), 빈 칸 사이에 두지 않음.
- 산정기준: 용역금액(입력), 낙찰하한율(0.79995), 기초금액=용역금액×낙찰하한율, 공종(건설) 입력 + 공종계수 IF수식 1칸(줄바꿈 '기지\n계수', 값칸 병합).
- 지분표 열: 구분 | 컨소사 | 실지분 | 조정PQ지분 | 예상지분금액 | 지역참여도 | 공종별비율.
  - 예상지분금액 칸은 과하게 넓히지 말 것(2칸 정도).
  - 구분 = 건설(여러 컨소사 행)/통신/소방(있을 때만). 조정PQ지분은 건설만.
  - 실지분 = 공종별 분리 SUMIF(건설=건설상주+건설기지 %합, 통신=통신상주%+통신기지%, 소방=소방기지%). 합 100%.
  - 예상지분금액 = 기초금액 × 실지분. 지역참여도 = (지역사 건설 조정PQ × 건설공종비율) + 통신·소방 공종비율. 공종별비율 = 분담비율.
- 컨소사 광장(책임,1번째)·케이제이(2번째) 고정, 나머지 입력칸(노랑 아님).

## 8. 서식
- 글꼴 맑은 고딕. 소숫점: 투입월수·환산비·인월수 0.00, % 0.00%, 금액 #,##0. 비고 가운데 정렬.
- **노랑 = PQ평가대상 행의 분야(D)·등급(E)·컨소사(G)만. 감리원(F)·비평가 행·입력칸은 노랑 없음.**
- **조정PQ지분 칸 = 빨강 굵은(medium) 바깥 테두리.**
- 표 테두리는 내용 있는 셀만(빈 월칸은 테두리 O, 표 바깥 빈 영역은 테두리·넓이 확장 금지).
- 소계 연녹(E2EFDA), 합계 연주황(FCE4D6), 헤더 살구(F2DCDB), 조정PQ헤더 강조(FFE699).
- **비고 문구·표 하단 문구(※/◈)는 첨부 원본 배치표에 적힌 그대로 쓴다. 원본에 없으면 공란으로 둔다(상주 비고가 원본에 비면 비워둠). 대괄호·부가설명·표준문구를 임의로 붙이지 않는다.**

## 9. 등급 대조
입찰설명서/공고문 12.1 평가대상 등급과 배치표 등급을 비교해 상이하면 빨간 글씨(같으면 표시 없음).

## 10. 인쇄 설정
A4 세로, 표 폭이 한 페이지에 들어가도록 축소(fitToWidth=1 또는 적정 %)해 페이지 나누기 미리보기를 깔끔하게.

## 11. 검증(필수)
recalc.py 후 수식 오류 0, 투입월수 총계 = 원본 총계, 실지분 합 100%, 예상지분금액 합 = 기초금액, % 합 100%.
